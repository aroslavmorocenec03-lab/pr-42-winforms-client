# Адаптація Windows Forms макетів ПР-44

Джерело: [pr-44-postservice-gui](https://github.com/aroslavmorocenec03-lab/pr-44-postservice-gui).

| Макет | Реалізація |
|---|---|
| `02-list.png` | Головна `PostingList`, таблиця і кнопки створення, редагування, видалення, оновлення |
| `03-new.png` | `PostingEditor` без запису; ціна лише для читання, обчислює сервер |
| `08-edit.png` | Та сама `PostingEditor` із завантаженим записом і доступною для редагування ціною |
| `04-validation.png` | `ErrorProvider`, перехід до першого помилкового поля, текстове пояснення |
| `07-delete.png` | Стандартний `MessageBox` із підтвердженням, номером і напрямком відправлення |

Макети головної сторінки, деталей та «Про програму» не утворюють окремих форм: завдання вимагає дві форми. `PostingList` одразу відкривається в `Program.Main`, а `PostingEditor` використовується як модальний діалог. Стандартні системні повідомлення не є додатковими власними формами застосунку.

Збережено світлий фон, темні заголовки, сині основні кнопки, червону кнопку видалення та всі бізнес поля DTO. Розміри адаптовано до настільного вікна; діалог можна змінювати за розміром, а список має прокручування й змінні ширини стовпців.
